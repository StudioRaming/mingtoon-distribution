# MingToon 0.1.8-dev.1

Prerelease / 사전 출시 / プレリリース

## English
- Added VPM package installation and update UI, with a DLL installer.
- Grouped identical shader bake requests and preserved recovery on failure.
- Distribution packages remove development features, developer logs, and non-license source comments. Required legal notices and user-facing recovery errors remain.
- Core BRP package. URP is a separate add-on. See the existing open-beta terms and support limits at https://studioraming.github.io/mingtoon-site/en/download/.

## 日本語
- VPMパッケージの導入・更新UIとDLLインストーラーを追加しました。
- 同一のシェーダーベイク要求をまとめ、失敗時の復旧処理を維持しました。
- 配布パッケージから開発用機能・開発ログ・ライセンス以外のソースコメントを除去します。必要な法的表示と復旧用エラー表示は維持します。
- BRPコア版です。URPは別アドオンです。オープンベータの利用条件と対応範囲は https://studioraming.github.io/mingtoon-site/ja/download/ をご確認ください。

## 한국어
- VPM 패키지 설치·업데이트 UI와 DLL 설치기를 추가했습니다.
- 동일한 셰이더 베이크 요청을 묶고 실패 시 복구 처리를 유지했습니다.
- 배포 패키지에서 개발 기능·개발 로그·라이선스 외 소스 주석을 제거합니다. 필요한 법적 고지와 사용자용 복구 오류 안내는 보존합니다.
- BRP Core 패키지이며 URP는 별도 애드온입니다. 기존 오픈 베타 이용 조건과 지원 제한은 https://studioraming.github.io/mingtoon-site/ko/download/ 에서 확인하세요.
